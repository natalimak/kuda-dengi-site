# Обязательная проверка сайта после каждого обновления

Это правило применяется после каждого изменения и новой загрузки сайта.

## До загрузки в GitHub

- В `index.html` есть прямое подключение `gtag.js` с идентификатором `G-37GQ5B9LB5`.
- В комплекте есть `analytics.js`.
- В `analytics.js` есть события `section_view` и `whatsapp_click`.
- Сохранены `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml` и файл подтверждения Google.
- Все локальные файлы, указанные в `index.html`, присутствуют в комплекте.

## После публикации

- Открыть `https://kuda-dengi.co.il/` и проверить оформление, фотографию и мобильный вид.
- Убедиться, что загружается `https://www.googletagmanager.com/gtag/js?id=G-37GQ5B9LB5`.
- Убедиться, что доступен `https://kuda-dengi.co.il/analytics.js`.
- Открыть GA4: `דוחות` → `זמן אמת`.
- Зайти на сайт в отдельной вкладке, прокрутить несколько секций и нажать WhatsApp.
- Проверить появление `page_view`, `section_view` и `whatsapp_click`.

Сайт нельзя считать готовым только потому, что он визуально открылся. Обновление считается проверенным лишь после подтверждения работы аналитики на опубликованном домене.
