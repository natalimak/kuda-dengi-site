Загрузите ВЕСЬ контент этой папки в корень репозитория GitHub Pages.

Важно:
1. index.html и папка assets должны находиться в корне репозитория.
2. Не удаляйте CNAME — он связывает сайт с kuda-dengi.co.il.
3. Разрешите замену файлов с совпадающими именами.
4. После загрузки дождитесь завершения GitHub Pages deployment.
